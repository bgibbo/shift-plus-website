Bring your schedule into view.

The integration makes current and next shift, working status, roster and unit details, leave balances, overtime totals, and roster/leave/overtime calendars available in Home Assistant. It also includes an optional monthly roster card with Android-matched duty colours and markers.

Android sends configuration and records. Home Assistant stores a replica and recalculates time-sensitive schedule values every minute. Shift + does not create household automations or control devices by itself.

STEP 01

Install from Marketplace or HACS.

Home Assistant 2026.11 or newer: Open Settings → Marketplace, search for Shift +, select it and install.

Older Home Assistant systems: If you already use HACS, open HACS → Integrations, search for Shift +, then download it.

  1. Restart Home Assistant only if the installation manager asks you to.
  2. Open Settings → Devices & services → Add integration and select Shift +.
  3. Do not add a custom repository for the normal public installation. Shift + is in the Marketplace/HACS default catalogue; allow the catalogue to refresh if it is not visible immediately.
STEP 02

Pair and perform the first sync.

  1. In the Shift + integration, press Create Android pairing QR.
  2. On the Android app, open Home Assistant, scan that QR and let the first sync complete.
  3. Check Last successful sync, then open the Shift + device to see populated roster, leave and overtime entities.
Keep pairing private.

The QR is single-use and expires after five minutes. Never share a live QR, purchase token or Home Assistant credentials.

STEP 03

Add the monthly roster card.

Open a dashboard, choose Edit dashboard → Add card → Manual, and use the YAML example in the monthly roster card guide ↗. For normal storage-mode dashboards, the JavaScript resource is registered automatically by the integration—there is no need to copy a lovelace folder or manually add a resource.

Use the card controls to choose a suitable font size, calendar cell size and density for a phone, tablet or desktop dashboard. Navigate months using the card arrows.

WHAT “REFRESH” MEANS

Keep the meaning of sync clear.

Refresh schedule recalculates Home Assistant’s local schedule. It does not wake or contact Android. Android synchronises when it next connects to Home Assistant.

For conflicts, review the integration’s Sync conflicts information and use Shift +: Resolve one sync conflict to choose the current or alternative record. Android receives the result on its next normal sync.

TROUBLESHOOTING

If something doesn’t look right.

Shift + is not visible in Marketplace or HACS
Refresh the catalogue, then search again. Do not add a custom repository for the normal public installation.
QR expired or pairing unavailable
Create a fresh QR, scan it within five minutes, confirm Premium is active, and make sure the phone can reach Home Assistant.
Roster card looks old or misses colours
Refresh the browser after an update. The integration uses a versioned resource URL for newly registered resources; avoid creating duplicate Shift + resources.
Wrong schedule or empty calendar
Check the active roster, unit and shift settings in Android. Open Shift + and allow synchronisation to complete.
Sync stopped
Check Last successful sync, Android pairing status and Premium renewal.
